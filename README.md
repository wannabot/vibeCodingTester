# Cat Variables Atelier

고양이 취향과 기분을 변수 카드로 보여주는 정적 웹사이트입니다.
각 카드는 GPT 이미지 생성을 위한 프롬프트, 상태값, 설명, 인라인 SVG 일러스트를 함께 제공합니다.

## 변경 요약

- 깨진 한국어 문구를 정상 UTF-8 텍스트로 복구했습니다.
- 메인 히어로, 오늘의 추천 변수, 카드 갤러리 문구를 읽기 쉽게 정리했습니다.
- `script.js`의 깨진 문자열을 고쳐 카드 렌더링과 랜덤 추천 버튼이 정상 동작하게 했습니다.
- `upload/index.html`도 루트 페이지와 같은 콘텐츠를 표시하도록 맞췄습니다.

## 파일 구성

- `index.html`: 메인 정적 페이지
- `style.css`: 레이아웃, 색상, 반응형 스타일
- `script.js`: 고양이 변수 데이터, 카드 렌더링, 추천 버튼 로직
- `upload/index.html`: 업로드 또는 배포용 보조 진입 페이지

## 확인 포인트

- 버튼을 누르면 오늘의 추천 고양이 변수가 무작위로 바뀝니다.
- 선택된 변수는 스포트라이트 영역과 갤러리 카드 강조 상태에 반영됩니다.
- 각 카드에서 GPT 이미지 생성용 프롬프트를 확인할 수 있습니다.

- 마음에 드는 변수 저장, 공유 기능 확장
